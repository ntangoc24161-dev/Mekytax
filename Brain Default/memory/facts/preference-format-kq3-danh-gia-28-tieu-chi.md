Đối với sheet `Danh_gia_28_tieu_chi` trong file KQ3:
- Không tô màu nền toàn bộ khung/dòng.
- Chỉ tô màu tại cột F (Mức độ rủi ro): Mức 'Cao' tô màu đỏ, mức 'Trung bình' tô màu vàng.

**Áp dụng:** Giữ nguyên quy tắc tô màu cột F khi sinh/chỉnh sửa file kết quả KQ3.
