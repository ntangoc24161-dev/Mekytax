Trên file `Bao_cao_cong_van.xlsx` tại sheet `NHAP_HO_SO`, cấu trúc các cột phân công hồ sơ:
- Cột I: Mã số thuế NNT (kích hoạt công thức STT và thống kê phụ trợ)
- Cột J: Tên NNT / Công ty
- Cột K: Địa chỉ rút gọn (rút gọn về cấp Phường/Xã để phân Tổ KT)
- Cột L: Tổ KT (KT1, KT2, KT3... căn cứ địa bàn quản lý, ví dụ Phường Hố Nai thuộc KT1)
- Cột M: Cán bộ xử lý (tra cứu từ DB NNT hoặc để trống cập nhật sau)
- Cột N: Tình trạng xử lý (mặc định gán 'Mới')
