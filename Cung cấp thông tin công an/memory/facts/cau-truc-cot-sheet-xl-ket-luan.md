Trên file `Bao_cao_cong_van.xlsx`, sheet `XL KET LUAN` được thiết lập cấu trúc bổ sung thêm 02 cột thông tin ngay sau cột Doanh nghiệp cần cung cấp (Tên NNT/Công ty):
- Cột 12: MST cty bán hóa đơn
- Cột 13: Tên cty bán hóa đơn
Mục đích nhằm theo dõi tách bạch giữa đơn vị mua vào cần kiểm tra xử lý vi phạm hành chính và các đơn vị bán hóa đơn rủi ro/bất hợp pháp theo kết luận điều tra.
