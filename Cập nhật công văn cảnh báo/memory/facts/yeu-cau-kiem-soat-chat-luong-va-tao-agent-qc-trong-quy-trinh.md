User yêu cầu có cơ chế kiểm soát công việc của từng trợ lý để tránh trường hợp bịa số liệu, bóc tách sai dữ liệu. Hệ thống thiết lập agent Kiểm soát chất lượng dữ liệu (QC) kiểm tra độc lập tại 4 điểm: (1) OCR (ký tự rác, bảng biểu, header/footer); (2) Bóc tách nạp sổ (số CV, ngày CV, MST 10 số, trùng lặp); (3) Đối chiếu NCC (đối chiếu danh sách rủi ro, ghi nguồn); (4) Soạn thảo (khớp dữ liệu sổ, trích dẫn luật, không bịa số liệu). Agent QC có quyền dừng quy trình yêu cầu agent sửa lại nếu phát hiện lỗi.
