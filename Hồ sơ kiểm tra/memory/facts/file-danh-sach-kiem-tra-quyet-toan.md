Người dùng lưu và quản lý file Excel theo dõi kiểm tra quyết toán tại trụ sở người nộp thuế trong thư mục:
`G:\Other computers\My Laptop\1. CONG TAC KIEM TRA\1- KIEM TRA\1. KIEM TRA TAI TRU SO NNT\00. Theo doi chung\`

- **File gốc:** `Danh sach kiem tra quyet toan.xlsx`
- **File làm việc duy nhất (có macro tự chuyển dòng):** `Danh sach kiem tra quyet toan pro.xlsm`
- Đã xóa bản `.xlsx` và các file backup `.bak`, chỉ duy trì 1 file `.xlsm` duy nhất.
