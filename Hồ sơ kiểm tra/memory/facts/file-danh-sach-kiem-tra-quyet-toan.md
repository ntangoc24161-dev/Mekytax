Người dùng lưu và quản lý file Excel theo dõi kiểm tra quyết toán tại trụ sở người nộp thuế trong thư mục:
`G:\Other computers\My Laptop\1. CONG TAC KIEM TRA\1- KIEM TRA\1. KIEM TRA TAI TRU SO NNT\00. Theo doi chung\`

- **File làm việc (có macro tự chuyển trạng thái):** `Danh sach kiem tra quyet toan pro.xlsm`
- **File gốc tham chiếu (giữ nguyên):** `Danh sach kiem tra quyet toan.xlsx`
- **Không dùng / không tạo lại:** `Danh sach kiem tra quyet toan - JAVIS PRO.xlsm` / `.xlsx`
- **Không tạo file bak** trong thư mục `00. Theo doi chung\`
