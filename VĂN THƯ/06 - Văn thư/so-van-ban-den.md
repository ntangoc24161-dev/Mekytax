# Sổ theo dõi văn bản đến

> Sổ gốc của Phòng Văn Thư. Loop `van-thu-dieu-phoi-don-doc` đọc bảng này mỗi vòng để phân
> việc và đôn đốc. Thêm một dòng mới là đủ để giao việc - không cần kích hoạt gì thêm.
>
> **Trạng thái:** `Mới` (chờ phân) · `Đã phân` · `Đang xử lý` · `Quá hạn` · `Xong`
> **Độ khẩn:** `Hỏa tốc` · `Thượng khẩn` · `Khẩn` · `Thường`

| Số đến | Ngày nhận | Số/ký hiệu VB | Cơ quan ban hành | Trích yếu | Độ khẩn | Phòng thụ lý | Hạn chót | Trạng thái | Kết quả báo lại |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

## Ghi chú vận hành
- Cột **Phòng thụ lý** và **Hạn chót** để trống khi nhập; Phòng Văn Thư tự điền khi phân việc.
- Cột **Kết quả báo lại** là chỗ phòng thụ lý ghi kết quả. Trống quá hạn chót thì bị tính là chậm.
- Hạn mặc định: Hỏa tốc trong ngày, Thượng khẩn 1 ngày, Khẩn 2 ngày, Thường 5 ngày làm việc.
