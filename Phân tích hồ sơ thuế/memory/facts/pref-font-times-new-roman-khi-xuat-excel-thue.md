Khi chỉnh hoặc xuất file Excel phục vụ kiểm tra thuế / đối chiếu CVCBRR (ví dụ `Tong_hop_NCC_mua_vao_CV_trang_thai.xlsx`, `Tong_hop_ben_mua_CVCBRR.xlsx`), đặt font **Times New Roman** cho toàn bộ workbook.

**Vì sao:** User viết rõ "đổi font chữ thành Time new roman" khi mở quyền chỉnh sheet.
**Áp dụng:** Các file Excel kết quả trong hồ sơ TTKT / sổ CVCBRR mà Javis xuất hoặc chỉnh theo yêu cầu tương tự.
