Người dùng yêu cầu dọn dẹp và tổ chức thư mục `ket-qua/` kiểm tra thuế theo mô hình 3 lớp:
- Gốc `ket-qua/`: Chỉ lưu duy nhất file báo cáo tổng hợp cuối cùng (`Phan_tich_ho_so_cong_ty_<TenDN>.xlsx`).
- Thư mục con `cau-thanh/`: Lưu các file phân tích chuyên đề độc lập để đối chiếu/tham khảo (bảng kê gốc, đối chiếu GTGT-TNDN, xét NCC mua vào CBRR, TNCN, BCTC).
- Thư mục con `sao-luu/`: Lưu trữ các file phụ trợ dạng `.json`, `.md` hoặc bản nháp lưu trữ kỹ thuật.
- Xóa bỏ các bản nháp trùng lặp hoặc lỗi font/1 sheet cũ để tránh lưu trữ 2 lần.
