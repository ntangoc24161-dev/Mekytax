Khi phân tích hồ sơ thuế thật, cần làm rõ/có sẵn: (1) thư mục hồ sơ tuyệt đối trên đĩa (XML/Excel); (2) MST + kỳ kiểm tra + loại NNT; (3) mục tiêu lần làm (chỉ mở hồ sơ / chạy engine / cả hai); (4) phạm vi ưu tiên (GTGT-HĐĐT, TNDN-BCTC, TNCN, GDLK, hoàn thuế, toàn bộ); (5) file còn thiếu thì ghi thiếu, không bịa số.

**Vì sao:** Thiếu đầu vào sẽ chạy lệch phạm vi hoặc bịa số liệu.
**Áp dụng:** Nhận folder rồi liệt kê file có/thiếu; hỏi nốt MST-kỳ-mục tiêu nếu chưa suy ra được từ thư mục.
