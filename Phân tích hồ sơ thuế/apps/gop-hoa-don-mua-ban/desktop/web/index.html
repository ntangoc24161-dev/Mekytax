Gộp hóa đơn mua vào - bán ra

Chạy ngay trên trình duyệt, không cần cài Python hay Excel. Mỗi công ty ra 1 file, 2 sheet có tiêu đề.

1. Chọn file nguồn

Kéo thả file .xlsx vào đây

Hoặc chọn nhiều file / cả thư mục xuất từ portal HĐĐT, bảng kê quý.

Chưa chọn file

    2. Công ty (tuỳ chọn)

    Để trống MST thì app tự nhận diện từng công ty trong lô file. Điền MST khi tất cả file thuộc đúng 1 doanh nghiệp.

    3. Kết quả theo công ty

    Chưa chạy. Chọn file rồi bấm Đọc và phân loại.

    Nhật ký

    File kết quả: 2 sheet Mua vào / Bán ra, tiêu đề đơn vị - MST - thời gian, sắp Ngày lập rồi Ký hiệu rồi Số HĐ, font Times New Roman, in A4 ngang co 1 trang rộng. Map cột theo tên header (kể cả chữ đ). Không gửi file ra ngoài máy.
