File `Danh gia PCVP.xlsx` trong thư mục `06_Tieu_chi_danh_gia` là hồ sơ tự đánh giá Quý III/2026 của đồng chí Mai Thị Ngọc Lan (Phó Chánh Văn phòng Đảng ủy phường Trấn Biên), không phải đảng viên Chi bộ 13. File này đóng vai trò mẫu thực tế (case study) để tham khảo cách điền 4 sheet: Kế hoạch (Mẫu 01), Danh mục sản phẩm (Mẫu 02), Chấm KPI 4 trụ A/B/C/D (Mẫu 02AB) và Bản tự đánh giá xếp loại (Phụ lục 30+70).
